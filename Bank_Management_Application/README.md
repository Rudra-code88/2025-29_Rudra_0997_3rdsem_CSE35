# Bank Management Application

A simple console-based Bank Management Application developed in C++.

## Features

- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- Display all customer accounts
- Store account data using file handling
- Menu-driven console interface

## Concepts Used

- Object-Oriented Programming
- Classes and Objects
- Vectors
- File Handling
- Functions
- Loops and Switch Case

## Data Stored

The application stores:

- Account Number
- Customer Name
- Account Balance

Account information is stored in `accounts.txt` so that data can be maintained between program runs.

## How to Run

1. Compile `main.cpp` using a C++ compiler.
2. Run the generated program.
3. Select an option from the menu.
4. Account data will be saved in `accounts.txt`.

## Project Files

- `main.cpp` - Main C++ source code
- `accounts.txt` - File used to store account records
- `README.md` - Project documentation
