# Student Management System

A simple console-based Student Management System developed in C++.

## Features

* Add student records
* Display all student records
* Update student information
* Delete student records
* Store student data using file handling
* Menu-driven console interface

## Student Details

The system stores:

* Student ID
* Name
* Age
* Course
* Email

## Technologies Used

* C++
* File Handling
* Object-Oriented Programming
* Standard Template Library (STL)

## How to Run

1. Download or clone this repository.
2. Compile `main.cpp` using a C++ compiler.
3. Run the generated program.
4. Use the menu to add, display, update, or delete student records.

## Data Storage

Student information is stored in `students.txt`, allowing the records to remain available after the program is closed.

## Project Purpose

This project was developed as part of the C++ programming internship to practice file handling, classes, vectors, functions, and menu-driven programming.
