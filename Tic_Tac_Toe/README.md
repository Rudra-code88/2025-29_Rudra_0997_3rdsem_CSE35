# Tic Tac Toe Game

A simple console-based Tic Tac Toe game developed in C++.

## Features

- Two-player game
- Dynamic 3×3 game board
- Players use X and O
- Checks for winning combinations
- Detects draw/tie
- Replay option after each game
- Simple console-based interface

## Concepts Used

- Arrays
- Loops
- Conditional statements
- Functions
- Basic C++ programming
- Game logic

## How to Run

1. Compile the `main.cpp` file using a C++ compiler.
2. Run the generated executable.
3. Enter positions from 1 to 9 to make moves.
4. Follow the instructions displayed on the screen.

## Game Rules

- Player 1 uses `X`.
- Player 2 uses `O`.
- Players take turns choosing an empty position.
- The first player to get three symbols in a row, column, or diagonal wins.
- If all positions are filled without a winner, the game is a draw.
