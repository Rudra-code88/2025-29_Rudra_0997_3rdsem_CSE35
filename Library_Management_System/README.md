# Library Management System

A simple console-based Library Management System developed in C++.

## Features

- Add new books
- Display all books
- Add library members
- Display members
- Issue books
- Return books
- Search books by title
- Search books by author
- Store book records using file handling

## Concepts Used

- Object-Oriented Programming
- Classes and Objects
- Vectors
- File Handling
- Menu-Driven Programming

## Data Storage

Book records are stored in `library.txt` using file handling.

## How to Run

Compile the program using a C++ compiler:

```bash
g++ main.cpp -o library
